### Commands and configuration

Run commands from `frontend`, independently of the backend:

```powershell
npm ci
npm run lint
npm run build
npm run dev
```

`dev` runs `next dev --port 3000`. `build` runs `next build`. `start` runs `next start --port 3000` after a build. `lint` runs `eslint . --max-warnings=0`; lint is separate because Next.js 16 does not run it during build. Use Ctrl+C to stop a server. Both server commands explicitly use port 3000, so `.env.local` does not control that port.

Git setup commands are `git init -b main`, `git add .`, and `git commit -m "chore: initialize Next.js frontend"`, run within this folder. Use `git log -1 --oneline` to see the commit identifier and `git status --short` to check for uncommitted changes. The parent workspace is not initialized as a repository.
